# Первичная установка системы

1. Устаналиваем Docker по [актуальному гайду](https://docs.docker.com/engine/install/ubuntu) или с помощью скрипта `./install/docker.sh`.

2. Устанавливаем Portainer (`install/portainer.yml`), там добавляем другие репозитории как stack.

3. [Настраиваем](https://www.dmosk.ru/instruktions.php?object=samba-ubuntu) Samba.
